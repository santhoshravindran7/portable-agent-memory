# Changelog

All notable changes to the Portable Agent Memory extension will be documented in this file.

## [0.1.0] - 2024-01-01

### Added
- Initial release
- Remember This, Remember Selection, Remember Fact commands
- Recall webview with color-coded memory cards
- Search Memory command with full-text search
- Export/Import `.pam` files
- Integrity verification
- Sidebar tree view organized by memory type
- Status bar showing memory count
- Auto-detection and install prompt for PAM CLI
